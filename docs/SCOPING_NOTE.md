# Scoping note (summary of the 16 Oct 2026 note de cadrage)

The full note is the owner's working document; this summary keeps what binds the project.

- **Choice**: FRDA first, as a methodological test bed with a clean causal anchor (FXN /
  frataxin); Parkinson (e.g. GSE202210, 12 donors / ~80k nuclei) kept for a later, narrower
  cross-disease extension.
- **Five principles**: a scientific need before any interface or agent; no restricted patient
  data without verified rights; never conflate associated genes, biomarkers, causal mechanisms
  and validated targets; evaluate on independent studies/donors; involve a biomedical expert early.
- **Mandatory checks before ingestion**: public ≠ downloadable ≠ freely reusable ≠ usable with an
  AI assistant; keep DOI/accession, download date, URL, access terms and licence for every source;
  never send DUA-bound, identifying or rights-restricted data to an LLM service.
- **Risks → responses**: LLM hallucination → every fact corroborated by a verifiable extraction
  or method; pseudo-replication → aggregate at donor level; abusive cross-disease transfer →
  compare functions first, document tissue/model; "ranking = drug" effect → always "preclinical
  hypotheses to examine".
- **Value measures**: published results reproduced; 100 % of assertions traceable to a study and
  a locatable result; at least one researcher willing to examine the result; pipeline re-runnable
  from manifests with pinned versions; a demonstrated improvement over existing resources on a task.
- **Update (owner, 16 Oct 2026)**: the target is raised from a hand-over deliverable to an
  **original, publishable contribution** (preprint), still produced by autonomous cloud routines.
